# Institute of Engineering & Management CSE (AI & ML) — Event Lab

A responsive HTML/CSS/JavaScript event website with an editorial AI-lab visual identity.

## Features
- Event timeline generated with JavaScript
- Category filtering
- Live IST clock
- Event countdown
- Registration validation
- Gallery hover archive
- Dark/light theme saved with localStorage
- Responsive mobile navigation
- Scroll reveal animations
- Editorial ticker and subtle magnetic buttons

## Run
Open `index.html` directly in a browser.

Replace the SVG files in `images/` with real event photos whenever you have them.
